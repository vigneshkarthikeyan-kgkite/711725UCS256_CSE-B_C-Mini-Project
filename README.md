Bank Management System 

A simple and efficient Bank Management System developed as a mini project using the C programming language. This project is designed to perform basic banking operations such as account creation, balance inquiry, deposit, withdrawal, and account management through a console-based interface.

This project helps in understanding the concepts of:

File Handling
Structures
Functions
Conditional Statements
Loops
Data Management in C

The system provides an easy-to-use interface for managing customer banking records and transactions. It is mainly developed for educational purposes to demonstrate how banking operations can be implemented using core programming concepts. Inspired by common banking mini-project structures and CRUD-based banking systems in C.

Features :

Create New Bank Account
Deposit Money
Withdraw Money
Check Account Balance
View Customer Details
Update Account Information
Delete Account
File-based Data Storage
Simple Console User Interface
Secure and Organized Record Management

Technologies Used :

Programming Language: C
Concepts Used: File Handling, Structures, Functions, Arrays
Platform: Console Application
Compiler: GCC / Turbo C / Code::Blocks / VS Code

Project Objectives :

To simplify basic banking operations digitally
To manage customer records efficiently
To understand real-time implementation of file handling in C
To improve problem-solving and programming skills

How to Run the Project 

Clone the repository:

git clone https://github.com/vigneshkarthikeyan-kgkite/711725UCS256_CSE-B_C-Mini-Project.git

Open the project folder

Compile the program:
gcc main.c -o bank

Run the executable:
./bank
